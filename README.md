Um projeto pessoal de portfólio para gerenciamento de jogos.

**Tecnologias:** Node.js, TypeScript, Express, PostgreSQL, Prisma e Docker.

* APIs REST
* Relacionamentos entre entidades
* Validação de dados
* ORM
* PostgreSQL
* Docker

* Integração com APIs externas
